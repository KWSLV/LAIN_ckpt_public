## 修改内容与原因

1. 修复 AMP 分支的梯度裁剪顺序：`backward -> unscale_ -> clip_grad_norm_ -> step`。修复前裁剪的是放大后的缩放梯度，`--clip-max-norm 0.1` 不能按预期约束真实梯度。
2. 新增命令行参数 `--scene-gate-post-l2-norm`。
3. SceneGate 融合后可再次执行 L2 normalization，避免 Gate 主要通过改变特征范数影响 logits。
4. SceneGate refine 脚本显式设置 Gate 学习率、梯度裁剪和融合后归一化。
5. resume 脚本只在显式提供 `GATE_LR` 时覆盖 checkpoint 中的 Gate 学习率。

## 关键参数或行为变化

- `--clip-max-norm 0.1` 在 AMP 下正式生效。
- `--scene-gate-post-l2-norm`：开启 SceneGate 融合后 L2 normalization。
- Gate refine 默认 `--lr-scene-gate 1e-4`。
