# 2026-08-09 A3续训20轮与A4三模块贡献诊断

修改时间：2026-08-09 22:25（Asia/Shanghai）

## 原因

- A3 初始脚本错误地只配置了 15 个 epoch，而 A 系列对照实验要求统一训练 20 个 epoch。
- 新增 A4：在 A3 的 Text/Object 参数基础上加入 Scene Gate，并在每轮评估三种新增模块的条件贡献。
- 用户提供的 38.12 日志实际为 Text Adapter-only 评估，没有开启 Scene Gate，因此不能从该日志提取 Gate 参数。

## A3 修改

- `scripts/training/UO_a2_a3_common.sh`：A3 总轮数由 15 改为 20。
- 兼容已经完成的旧 A3 `epochs=15` 参数文件；恢复 `ckpt_*_15.pt` 后继续运行第16至20轮。
- 新增 `UO_a3_continue_to20.sh` 和后台包装脚本。
- 续训使用 `--resume`，恢复模型、优化器、学习率调度器、epoch、iteration 和 AMP scaler，不重新初始化。

## A4 参数

- 总轮数：20；seed：66；`adapter_pos=last`。
- Text：dim=64、rank=4、alpha=16、residual scale=0.05、dropout=0.1、LR=2e-4。
- Object：rank=4、LR=2e-4。
- 共享 LAIN：head LR=5e-4、ViT LR=2e-4、StepLR drop=10。
- Scene Gate：v5、pair、hidden=128、rank=16、dropout=0.1、alpha=0.02、`standardized_tanh`、init std=1e-3、start epoch=1、LR=1e-3。
- Gate 配置选择依据：服务器现有 Gate 实验中，`standardized_tanh + alpha=0.02` 的 Gate-only refine 出现可测正贡献；38.12 Text-only 日志本身没有 Gate 参数。

## 贡献度输出

每轮依次计算：

- Gate贡献 = 完整模型mAP - Gate关闭mAP；
- Text贡献 = 完整模型mAP - Text Adapter关闭mAP；
- Object贡献 = 完整模型mAP - Object Adapter关闭mAP。

输出位置：

- `scene_gate_diagnostics.json`
- `scene_gate_diagnostics.csv`
- `module_contributions.png`，包含 Full、Unseen、Seen 三个子图；
- W&B 的 `module_contribution/gate_*`、`text_*`、`object_*` 曲线。
