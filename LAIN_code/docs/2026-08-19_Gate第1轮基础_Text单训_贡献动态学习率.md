## 动态学习率

初始`lr_text_adapter=2e-4`。每轮结束后计算：

```text
Text Unseen贡献 = 全开Unseen mAP - 关闭Text后的Unseen mAP
```

- 贡献严格超过0.05：从下一轮开始将学习率降至`5e-5`
- 贡献严格超过0.10：从下一轮开始将学习率降至`1e-5`
- 学习率只降低、不回升
- 当前贡献、触发条件和下一轮学习率写入JSON、CSV和W&B
