# LAIN 5 轮 + LAIN/Object 15 轮动态回滚重训

- 修改时间：2026-08-21 01:04:02 +08:00
- 本次仅编写、部署并校验代码与脚本，不启动训练。
- 脚本：`scripts/training/UO_lain5_object15_dynamic_retry20.sh`
- 后台脚本：`scripts/training/UO_lain5_object15_dynamic_retry20_background.sh`
- 默认输出：`/root/autodl-tmp/Lain/UO_lain5_object15_dynamic_retry20_seed66/checkpoints`

## 基础参数

新训练从 DETR 与 CLIP 预训练权重开始，不加载 A4ALL checkpoint。LAIN 主体沿用 `UO_a4all_seed66` 的训练配置：

- `lr/head=5e-4`
- `lr/vit=2e-4`
- `weight_decay=1e-4`
- `alpha=0.5`
- `gamma=0.2`
- `hyper_lambda=2.8`
- `box_score_thresh=0.2`
- `min_instances=3`
- `max_instances=15`
- `CSC=True`
- `N_CTX=36`
- `adapter_pos=all`

Object Adapter 使用 `rank=4`、初始 LR `2e-4`。Text Adapter 与 SceneGate 全程不创建/不开启。

## 逻辑 epoch 与模块状态

- 逻辑 Epoch 1～5：`use_obj_cond_adapter=False`，Object 不进入 forward；Object 参数同时设为 `requires_grad=False`。只训练原 A4ALL 中属于 LAIN 本体的 head/ViT 参数。
- 逻辑 Epoch 6～20：`use_obj_cond_adapter=True`，Object 参数恢复 `requires_grad=True`；只训练 LAIN 本体与 Object。
- 每个 attempt 开始均断言：Gate OFF、Text OFF、DETR frozen、固定 scheduler 为 `None`。

虽然 Object 参数组从初始化时即存在于 AdamW，以便完整记录和动态调整第三组 LR，但在前 5 个逻辑 epoch 中 Object 同时 bypass forward 且冻结，因此没有梯度和参数更新。

## 禁用固定 scheduler

新增 `--disable-lr-scheduler`。脚本同时记录 `--lr-drop 0`，但不会创建 StepLR，因此原来的 `lr_drop=10` 和任何固定 scheduler 都不生效。三个 LR 只会被以下动态规则修改。

## 动态 LR 与回滚

1. 当前训练历史 best 只来自已经接受的逻辑 epoch；第一个逻辑 epoch自动接受并建立 best。
2. 首次接受的 Unseen mAP 达到或超过 `37.5` 时，head/ViT/Object 一次性降到各自初始 LR 的 `1/10`。如果某组 LR 已被此前 rollback 降得更低，则保持更低值，绝不回升。该触发全程最多执行一次。
3. 达到 `37.5` 前，如果当前 attempt 比历史 best 下降超过 `0.15`，拒绝该 attempt。
4. 达到 `37.5` 后，如果下降超过 `0.05`，拒绝该 attempt。
5. 拒绝时加载 `best_unseen.pt` 的模型权重；以当次实际 LR 为基础全部乘 `0.5`；创建全新的 AdamW 和 AMP GradScaler；重训同一个逻辑 epoch。
6. 重训仍不满足阈值时继续重复，不设置最大 retry 次数。失败 attempt 不增加逻辑 epoch。
7. LR 只允许降低，后续不恢复。

## checkpoint、失败日志与 W&B

- 每个被接受的逻辑 epoch 保存常规 checkpoint；历史 best 始终保存为 `best_unseen.pt`。
- 失败 attempt 在 checkpoint 保存前已经被拦截，因此不会生成失败 `.pt`。
- 所有 attempt：`staged_retry_attempts.jsonl/.csv`。
- 仅失败 attempt：`staged_retry_failures.jsonl`。
- 失败日志记录 Full/Unseen/Seen、当次及下一次三个 LR、retry、累计 rollback、原因、阈值阶段、回滚目标 checkpoint、iteration 和 Object forward 状态。
- 失败 attempt 不运行贡献度评估，不调用任何用户指标 `wandb.log`。
- W&B 只写入接受的 20 个逻辑 epoch。保留现有 Full/Seen/Unseen、Gate/Text/Object contribution 结构：Gate/Text 全程为 0；Epoch 1～5 Object contribution 为 0；Epoch 6～20 Object contribution通过真实 Object-OFF 评估获得。
- W&B 每个接受 epoch 新增：`lr/head`、`lr/vit`、`lr/object`、`retry_count`、`rollback_count`，并补充 next LR、累计 rollback、一次性触发和 Object forward 状态。
